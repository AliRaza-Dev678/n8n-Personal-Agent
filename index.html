Privacy Policy

Last updated: July 26, 2026

This Privacy Policy describes how the n8n Personal Agent ("the App") handles information when you interact with it, including via WhatsApp.

What This App Does

This is a personal automation assistant built for learning and personal use. It connects to WhatsApp to receive messages and respond using an AI agent that can access calendar, email, task, and note-taking tools on behalf of the account owner.

Information We Collect

When you message this app via WhatsApp, we receive the message content and your WhatsApp phone number in order to process your request and send a reply. This data is used only to generate and deliver a response and is not sold, shared with third parties, or used for advertising.

How Information Is Used

  • To process incoming messages and generate relevant responses
  • To perform requested actions such as creating calendar events, tasks, or notes on the account owner's connected services

Data Storage

Message data is processed to generate a response and is not intentionally retained beyond what is necessary for the automation workflow to function, except where conversation memory is used to maintain context within a session.

Third-Party Services

This app may interact with third-party services (such as Google Calendar, Gmail, Google Tasks, and Google Docs) strictly to fulfill user requests. These services have their own privacy policies governing their use of data.

Contact

This is a personal, non-commercial project. For questions about this policy, please reach out via the contact information associated with the developer's GitHub profile.
